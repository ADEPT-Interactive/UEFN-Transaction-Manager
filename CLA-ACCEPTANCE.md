# CLA Acceptance Process

This is the designated acceptance process for the [ADEPT Contributor License
Agreement](CLA.md) version 1.2.

Before AD3PT Interactive Inc. merges or otherwise accepts a Contribution, the
contributor must post the following statement as a comment on the relevant
GitHub pull request:

```text
I have read and agree to the ADEPT Contributor License Agreement, version 1.2.
I agree that this comment is my electronic signature and that the Agreement
binds me for this Contribution.

Legal name: <your full legal name>
GitHub identity: <your GitHub username>
Date: <YYYY-MM-DD>
```

The contributor must replace every placeholder and post the statement from the
GitHub account submitting the Contribution. A maintainer must record the URL
of that comment in the pull request, verify that the accepted CLA version is
1.2, and confirm that the contributor had authority to submit the work.

Opening a pull request, creating a fork, checking a template box, or posting a
patch without this affirmative statement is not CLA acceptance. If the CLA
version changes, a new acceptance is required before a Contribution covered by
the new version is accepted.
