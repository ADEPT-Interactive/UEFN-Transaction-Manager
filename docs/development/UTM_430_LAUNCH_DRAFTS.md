## Product summary

UEFN Transaction Manager is a visual Windows app for building Fortnite in-island transactions in UEFN. It creates and validates entitlements, offers, alternates, bundles, storefronts, dynamic purchases, icons, and generated Verse. Version 4.3 adds optional UTM MCP and a packaged Agent Skill, so compatible coding agents can work with the same catalog while gameplay logic stays in the creator’s Verse.

## Existing-project migration demo storyboard

Target length: 30–60 seconds. Use real captures and real tool results; do not fabricate agent chat, terminal output, purchase results, or success states.

1. Show the existing project’s raw Marketplace Verse and a few associated project icons.
2. Show the agent receiving a concise migration request in the real compatible client.
3. Show UEFN MCP project search locating the existing Verse and assets.
4. Show the agent mapping transaction semantics and presenting a dry-run summary.
5. Show UTM’s catalog populating with the unambiguous entitlements, offers, bundle, and storefront objects.
6. Show the existing `Texture2D` being discovered and adopted through the UTM workflow.
7. Show the agent reading UTM’s generated integration contract rather than guessing symbols.
8. Show project Verse callers rewritten while gameplay calculations and consequences remain in project code.
9. Show save, BuildAll/compile, and the real zero-error result.
10. End on the populated UTM catalog and connected project state.

If a mapping is ambiguous, show the workflow stopping for review instead of presenting an automatic success.
